# Translations

Notifier provides translations for the following locales:

| Code | Native | English |
|:---|:---|:---|
| `da` | Dansk | Danish |
| `de` | Deutsch | German |
| `es` | Español | Spanish |
| `fi` | Suomi | Finnish |
| `fr` | Français | French |
| `it` | Italiano | Italian |
| `ja` | 日本語 | Japanese |
| `ko` | 한국어 | Korean |
| `nb` | Norsk Bokmål | Norwegian Bokmål |
| `nl` | Nederlands | Dutch |
| `pl` | Polski | Polish |
| `pt` | Português | Portuguese |
| `pt-BR` | Português Brasileiro | Brazilian Portuguese |
| `ru` | Русский | Russian |
| `sv` | Svenska | Swedish |
| `tr` | Türkçe | Turkish |
| `zh-CN` | 简体中文 | Simplified Chinese |
| `zh-TW` | 繁體中文 | Traditional Chinese |

Craft automatically loads a matching translation based on each user's language preference. No configuration is required.

## Contributions

To suggest changes or request support for a new language, please submit a ticket on [GitHub](https://github.com/doublesecretagency/craft-notifier/issues).
