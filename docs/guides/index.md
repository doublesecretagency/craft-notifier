# Common Solutions for Common Problems

There are a handful of common patterns which can be easily resolved using Notifier.

Here are some frequent use-cases...

### [When a new User registers, email Admins for approval](/guides/approve-new-user-registration)

Email your Admins when someone registers, with a direct link to review and activate the new account.

### [When a User is activated, send them a "Welcome" email](/guides/welcome-email-for-new-users)

Send a personalized email to a new User when their account is activated.
